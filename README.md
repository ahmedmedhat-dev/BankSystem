# Bank Management System

A Java-based Bank Management System designed to simulate core banking operations with a structured object-oriented approach. The project provides functionalities for managing user accounts, authentication, employee and admin operations, and transaction processing through a simple and organized system architecture.

## Features

* User registration and login system
* Account creation and management
* Deposit and withdrawal transactions
* Admin and employee management
* Client information handling
* Transaction history management
* Database connectivity and data storage
* Object-Oriented Programming (OOP) principles implementation

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* File Handling / Database Management
* Java Collections

## Project Structure

* `Account.java` → Handles bank account operations
* `Admin.java` → Admin functionalities
* `Client.java` → Client data management
* `Database.java` → Database connection and operations
* `Employee.java` → Employee functionalities
* `Login.java` → User authentication system
* `Signup.java` → User registration system
* `Transaction.java` → Transaction processing
* `User.java` → Base user class
* `Main.java` → Application entry point

## Objectives

The main goal of this project is to demonstrate the implementation of a banking system using Java while applying software engineering concepts such as:

* Encapsulation
* Inheritance
* Polymorphism
* Abstraction
* Modular Programming

## How to Run

```bash
javac Main.java
java Main
```
